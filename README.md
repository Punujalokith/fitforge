# FitForge — Gym Management System

A full-stack gym management platform built for **PowerZone Fitness**. It combines a Next.js web dashboard for gym admins with a Flutter mobile app for members and coaches.

---

## Overview

| Layer | Technology | Purpose |
|-------|-----------|---------|
| Web Dashboard | Next.js 15, TypeScript, Tailwind CSS | Admin panel — manage members, trainers, payments, classes |
| Mobile App | Flutter (Dart) | Member & coach app — QR check-in, goals, shift management |
| Backend | Firebase Firestore + Firebase Auth | Real-time database and authentication |
| Admin API | Next.js API Routes + Firebase Admin SDK | Server-side user creation and password management |
| AI | Anthropic Claude API | AI-generated gym announcements |

---

## Features

### Web Dashboard (`/web`)
- **Members** — Add/edit members, auto-generate FF-XXXX IDs, temp password credentials modal, payment history
- **Trainers** — Add coaches with FC-XXXX IDs, temp password flow, on-duty shift toggle
- **Attendance** — Real-time check-in log, gate open/close control
- **Gate Scanner** — Full-screen USB QR kiosk; handles FF-XXXX member and FC-XXXX coach codes
- **Payments** — Record payments, plan upgrade/downgrade with pro-rata credit
- **Analytics** — KPI cards, revenue trend, membership breakdown charts
- **Classes** — Schedule gym classes, set capacity, assign coaches
- **Renewals** — Approve or reject membership renewal requests
- **Announcements** — Broadcast messages with AI-assisted writing (Claude)
- **Settings** — Gym name, contact info, plan pricing

### Mobile App (`/mobile`)
- **Role Selection** — Separate login flows for members (cyan) and coaches (green)
- **Member Home** — Live membership card, gate status, on-duty coaches list
- **QR Check-in** — FF-XXXX QR code displayed for USB scanner at gate
- **Attendance** — Personal check-in history with calendar view
- **Goals** — Animated progress rings, weekly workout targets
- **Profile** — Membership details, payment history, sign out
- **Coach Home** — Shift start/end card, FC-XXXX QR code, today's check-in stats
- **Force Password Change** — First-login screen to replace temp password

## Setup

### Prerequisites
- Node.js 18+
- Flutter 3.x
- Firebase project with Firestore + Authentication enabled
- Firebase Admin SDK service account JSON

### Web Dashboard

```bash
cd web
npm install
```

Create `web/.env.local`:

```env
# Anthropic API (for AI announcements)
ANTHROPIC_API_KEY=your_anthropic_api_key

# Firebase Admin SDK
FIREBASE_PROJECT_ID=your_project_id
FIREBASE_CLIENT_EMAIL=your_service_account_email
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

> **Note:** `.env.local` is excluded from git. Never commit your private key.

```bash
npm run dev        # Development server — http://localhost:3000
npm run build      # Production build
npm start          # Start production server
```

### Mobile App

```bash
cd mobile
flutter pub get
```

Ensure `mobile/lib/core/firebase_options.dart` has your Firebase project config (generated by `flutterfire configure`).

```bash
flutter run                         # Run on connected device
flutter build apk --release         # Build Android APK
```

## Authentication Flow

```
Member/Coach opens app
        |
   Role Selection
        |
   Login Screen  ──── Firebase Auth (email + password)
        |
   Firestore check (members / trainers collection)
        |
   First login?  ──── Force Password Change Screen
        |
   Main App (member dashboard or coach home)
```

- **Members** are identified by `FF-XXXX` IDs stored in the `members` Firestore collection
- **Coaches** are identified by `FC-XXXX` IDs stored in the `trainers` Firestore collection
- After successful auth, the app verifies the user exists in Firestore — unregistered Firebase users are auto signed out
- Temp passwords are stored in Firestore only until first login; they are deleted after the user sets their own password

## Gate Scanner

The gate scanner page (`/dashboard/gate-scan`) works with any USB HID QR code scanner:

- **FF-XXXX** → member check-in: validates membership expiry, logs attendance
- **FC-XXXX** → coach shift toggle: starts or ends on-duty shift

The scanner types the QR content like a keyboard followed by Enter. No special driver or configuration needed.
